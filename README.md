# ScreenColorFullscreen

ブラウザ上で HSV（色相・彩度・明度）を操作し、画面全体の色を調整するシンプルなフルスクリーンカラーツールです。単一の `index.html` で完結しており、ローカルで開くだけで動作します。

## 構成

```
.
├── index.html   # UI・スタイル・スクリプトを含む単一ファイルアプリ
└── README.md
```

## 使い方

1. `index.html` をブラウザで開きます。
2. 右下のコントローラで HSV スライダーを操作して背景色を変更します。
3. 右上のボタンでコントローラを折りたたみできます。
4. 画面をダブルクリックするとフルスクリーン表示に切り替わります。

## 主な機能

- HSV スライダーによる背景色のリアルタイム変更
- お気に入り色の保存・選択・削除
- 画面ダブルクリックでフルスクリーン切り替え
- マイク入力に反応して色相を変化させる「音に反応」モード

## 開発メモ

- 外部依存はなく、ビルド手順は不要です。
- ブラウザのマイク利用許可が必要な場合があります（「音に反応」モード）。
